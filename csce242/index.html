CSCE 242 is a web design course which focuses on how to build websites using HTML code.

Here you will find my Github link: CSCEAlex on Github

Assignments

Assignment 1 – Basic HTML

First assignment introducing structural HTML elements, proper document nesting, and basic webpage markup.

Assignment 2 – Basic CSS

Second assignment applying CSS rules, styling fonts, colors, borders, and margins across elements.

Assignment 3 – Page layout

Third assignment designing multi-column responsive page layouts using CSS Flexbox and media queries.

Assignment 4 – Wireframing

Fourth assignment creating wireframes for a responsive homepage layout.

Assignment 5 – JavaScript Basics

Fifth assignment incorporating interactive JavaScript features including speech bubbles, select inputs, and sticker toggles.

Assignment 6 – JavaScript Basics

Sixth assignment incorporating interactive JavaScript features with counting and calculations.

Assignment 7 – Car Loops

Seventh assignment designing a road with looped car placement.

Assignment 8 – Map Arrays

Eighth assignment working with arrays and maps.

Assignment 9 – CAD Project Backend
